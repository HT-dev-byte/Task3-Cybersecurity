# Burp Suite Advanced — Intruder Fuzzing

## 1. Objective and Methodology

### Objective

The objective was to demonstrate the use of **Burp Suite's Intruder tool** to perform basic fuzzing against a web application parameter. Fuzzing involves sending a range of unexpected or specially crafted inputs and observing how the application responds.

### Methodology

A request was captured using **Burp Suite Proxy** and examined for use with **Intruder**. A suitable request parameter was selected for testing, and the **Sniper** attack type was used to test one parameter at a time.

A small set of test inputs was supplied to the selected parameter. The inputs included special characters and strings commonly used for security testing.

The responses were then compared with the normal application response to identify observable differences in status codes, response length, error messages, or application behavior.

## 2. Payloads Used for Fuzzing

The test inputs included a combination of special characters and common security-testing strings, such as:

```text
'
"
admin'--
<script>alert(1)</script>
!
```

These inputs were selected to examine how the application handles unexpected characters and commonly encountered injection patterns.

## 3. Analysis of Fuzzing Results

The responses generated by Intruder were compared with the application's baseline response.

The following characteristics were considered during the analysis:

* HTTP status codes
* Response length
* Error messages
* Changes in application behavior
* Whether supplied input was reflected in the response
* Unexpected differences between requests

Differences between responses were treated as indicators for further investigation rather than automatic proof of a vulnerability. For example, an error caused by a special character may indicate inadequate input handling, while reflected input may warrant additional testing for XSS.

## 4. Conclusion

Burp Suite Intruder provides an efficient method for testing how a web application responds to a variety of unexpected inputs. By automating payload delivery and allowing responses to be compared against a baseline, Intruder can help identify parameters that may require further security investigation.

The exercise demonstrated the use of **Burp Suite Proxy for request interception** and **Intruder for automated parameter testing**, providing a practical introduction to web application fuzzing and security testing.
